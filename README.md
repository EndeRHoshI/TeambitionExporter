# Teambition 一键导出 v1.0.0

点击插件图标，在居中的保存窗口选择目录后导出，原问题单不跳转。支持缺陷列表、版本库等入口中的问题单弹窗；会排除页面头像等界面图片。

## 怎么更新插件

代码更新后，**重新载入一次插件目录即可**：

1. 打开 `chrome://extensions`，开启「开发者模式」。
2. 点「加载已解压的扩展程序」。
3. 重新选择 `你本地的 TeambitionExporter` 文件夹。

如果已加载这个目录，也可以直接点插件卡片上的「重新加载」（圆形箭头）按钮。无需移除插件或运行安装命令。请等正在进行的导出结束再更新。

插件「错误」页面可能保留历史记录。排查时先点「全部清除」，重新加载插件，再导出一次；若出现新错误，截图发给我，或从插件选项复制排查日志。

## 平时怎么用

1. 打开具体问题单，展开需要的内容，点击插件图标。
2. 在居中的保存窗口中点「选择目录并导出」，选择想保存到的父目录。
3. 窗口会显示当前附件名称、下载大小和进度条；总大小未知时显示活动进度，保存阶段显示文件数量进度。导出过程中保留保存窗口和问题单页面，完成后点「复制路径并关闭」，会重新复制文件夹绝对路径，成功后关闭窗口。未设置绝对路径时只显示「关闭」。

Chrome 的目录选择器要求在可见页面中点击按钮，因此仍需点一次“选择目录并导出”。保存窗口使用不带标签栏、地址栏的小窗口，居中于原浏览器窗口；系统目录选择器的位置由 macOS/Chrome 决定。如出现查看或修改文件的授权提示，请点允许。

每次导出都重新选择目录，不再依赖之前的临时授权，也不用先去选项里点“重新授权”。目录选择器默认建议 Documents，Chrome 也可能记住上次位置，可以选择其他目录。取消选择不会开始导出。

例如：`所选目录/GXXE-10001/`，里面有 `issue.md`、`assets/`、`manifest.json` 和 `debug-log.json`，不额外生成问题单 ZIP。同一问题单再次导出会新建带序号的目录，不覆盖旧文件。日志附件本身的 RAR/ZIP 保留原样。

## 自动复制路径（可选）

如果希望导出后自动复制问题单文件夹的绝对路径，可在选项中填写**所选文件夹的真实绝对路径**，点「保存复制路径」。

“保存复制路径”只保存用于剪贴板的文字，不更改保存位置，也不申请权限。例如实际选择 Documents，这里填写 `/Users/your-name/Documents`，导出后复制 `/Users/your-name/Documents/GXXE-10001`。

浏览器不会提供所选目录的绝对路径，因此这项需要你核对。**留空不影响导出**，只是不自动复制绝对路径。切换到另一个目录时会清空旧路径，避免复制错误位置。

点击窗口左上角的系统关闭按钮只会关闭，不会复制路径。请使用页面中的「复制路径并关闭」。

## 提醒和排查

- 导出失败或附件缺失时弹出系统通知，点击通知可查看详情和日志。
- 导出结果显示在中间的保存窗口，不再显示网页右上角提示；图标悬停提示仍保留。
- 图标不再显示成功、失败或进度文字标记。结果在保存窗口中显示，历史结果仍在选项中。
- 附件没取齐时，问题描述和 manifest.json 会标明不完整，窗口提示附件缺失。
- 右键插件图标 →「选项」→「复制诊断信息」，粘贴给我即可排查。

系统关闭 Chrome 通知时，通知可能不显示，仍可在保存窗口查看结果。文件直接写入授权目录，可能不显示在 Chrome 下载列表中；日志附件的临时下载会被自动取消再打包，出现已取消记录是正常现象。

## 第一次安装

打开 `chrome://extensions`，开启「开发者模式」，点「加载已解压的扩展程序」，选择 `TeambitionExporter` 文件夹，然后按上面的步骤导出。

需要 Chrome 116+。单次附件总量上限 256 MB，只导出页面已经加载的内容。

## 本地开发

Node.js 20+，无需 `npm install`：

```
npm test
npm run check
```

ZIP 兼容性测试使用 macOS 自带的 `unzip`。

## 数据与隐私

插件使用当前登录的 Teambition 页面读取问题描述和附件，文件保存到你选择的本地目录。导出的描述、截图、日志可能包含内部信息，请勿提交到源码仓库。目录句柄和选填路径保存在本机 Chrome 扩展存储中，不包含在插件安装包里。

仓库中的问题单编号、文件名和路径均为演示数据。支持 `GXXE-数字`、`QHFG-数字` 等问题单编号：前缀以大写字母开头，可包含大写字母和数字，最长 32 位。保存目录自动使用当前问题单编号。

测试运行 `npm test`（主要模拟 Chrome 接口）和 `npm run check`。自动测试不等同于真实浏览器的目录授权、窗口显示和系统剪贴板验证。

## 目录结构

```text
assets/icons/  插件图标
src/           插件页面和运行代码
scripts/       图标生成、检查和打包工具
tests/         自动化测试
manifest.json  Chrome 插件入口配置
```

安装或重新加载时仍选择项目根目录（包含 `manifest.json` 的目录），不要选择 `src`。

运行 `npm run package` 生成 `dist/TeambitionExporter-版本号.zip`，只包含运行文件、图标和 README。打包使用 Python 3，无需安装第三方依赖。
