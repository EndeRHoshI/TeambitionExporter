# Teambition 一键导出 v0.3

打开问题单，点一下插件，就会下载描述、截图和日志，并复制保存目录的完整路径。

## 第一次安装

1. 解压 `teambition-exporter.zip`。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压后的 `teambition-exporter` 文件夹（里面有 `manifest.json`）。
4. 在 Chrome 右上角的拼图菜单中，找到插件并固定，方便下次使用。

**装过旧版？** 用新版文件替换原插件文件夹里的内容，再到 `chrome://extensions` 点该插件的刷新按钮。

## 怎么用

1. 在 Chrome 登录 Teambition，打开要导出的问题单。
2. 展开需要的描述、评论和附件，让内容加载出来。
3. 点插件图标，等待进度页完成。期间不要关闭原问题单或进度页。
4. 回到这里直接粘贴，发给我保存目录的路径。

如果 Chrome 询问是否允许多个文件下载，选「允许」。复制路径失败时，点进度页的「重新复制路径」。

## 文件在哪里

在 Chrome 的下载文件夹 → `Teambition` → 本次问题单文件夹中：

- `issue.md`：问题描述。
- `assets`：截图和日志附件。
- `manifest.json`：哪些文件下载成功、哪些失败。
- `debug-log.json`：插件运行记录，方便我排查。

## 出错了怎么告诉我

**不用打开开发者工具。**

在插件进度页点「一键复制诊断信息」，粘贴发给我就行。也可以点「保存排查日志」，把保存后的文件路径发给我。

即使没有下载成功，也可以复制诊断信息。最好保留进度页，先复制日志再关闭或更新插件。诊断信息会记录失败步骤和原因，下载地址中的签名参数会隐藏。

## 这次试用

这是待你在 Chrome 验证的试用版。真实问题单的日志下载按钮已经验证能触发下载；插件的完整下载和复制流程还需要这次试用确认。

插件只能导出页面已经加载的内容。发现漏图、漏附件或下载失败，把诊断信息发给我继续修改。

## 本地开发

源码就在这个文件夹中，Chrome 加载这个文件夹即可。无需安装依赖。

安装 Node.js 20 或更新版本后，在此目录运行：

```sh
npm test       # 检查下载匹配和排查日志
npm run check  # 检查 JavaScript 语法
```

修改代码后，在 Chrome 扩展管理页点插件的刷新按钮，再打开问题单重试。
